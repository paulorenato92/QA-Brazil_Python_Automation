# QA-Brazil Python Automation

Projeto de automação de testes desenvolvido durante a formação em Quality Assurance.

## Sobre o projeto

Este projeto apresenta a automação de testes de uma aplicação web, utilizando Python e ferramentas voltadas para testes automatizados.

## Tecnologias utilizadas

- Python
- Selenium WebDriver
- Pytest
- Git
- GitHub

## Estrutura do projeto

- `main.py` — execução principal dos testes
- `pages.py` — elementos e páginas da aplicação
- `helpers.py` — funções auxiliares
- `data.py` — dados utilizados nos testes
- `requirements.txt` — dependências do projeto

## Objetivo

Praticar a criação e execução de testes automatizados, aplicando conceitos de Quality Assurance e automação de testes Web.
