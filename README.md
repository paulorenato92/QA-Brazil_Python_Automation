# QA-Brazil Python Automation

Projeto de automação de testes Web desenvolvido durante a formação em Quality Assurance.

## Sobre o projeto

Este projeto apresenta uma suíte de testes automatizados para a aplicação Web Urban Routes, utilizando Python, Selenium WebDriver e Pytest.

Os testes foram desenvolvidos para validar diferentes funcionalidades e fluxos da aplicação, aplicando conceitos de automação de testes e Quality Assurance.

## Tecnologias utilizadas

- Python
- Selenium WebDriver
- Pytest
- Git
- GitHub

## Estrutura do projeto

- `main.py` — contém os testes automatizados.
- `pages.py` — contém os elementos e ações das páginas utilizadas nos testes.
- `helpers.py` — contém funções auxiliares utilizadas durante a automação.
- `data.py` — contém os dados utilizados nos testes.
- `requirements.txt` — lista as dependências necessárias para o projeto.

## Cenários automatizados

Entre os cenários testados estão:

- Seleção de rota;
- Seleção de tarifa;
- Preenchimento de dados;
- Validação de informações;
- Seleção de forma de pagamento;
- Fluxos relacionados ao pedido;
- Interações com a aplicação.

## Objetivo

Praticar a criação e execução de testes automatizados, aplicando conceitos de Quality Assurance e automação de testes Web.
